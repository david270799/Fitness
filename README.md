# IRON — личное фитнес-приложение для Android

Дневник тренировок для одного человека: силовые, кардио и интервальные программы, растяжка,
ежедневные мини-челленджи, замеры тела, напоминания о витаминах и лекарствах, ассистент на Gemini.
Интерфейс полностью на русском, единицы — кг, см, ккал. Без рекламы, аккаунтов, аналитики и биллинга.
Данные хранятся только на телефоне.

## Стек

Kotlin · Jetpack Compose · Material 3 · Navigation Compose · MVVM + Repository · Coroutines/Flow ·
Room · DataStore · EncryptedSharedPreferences · Hilt · Coil · WorkManager · AlarmManager ·
Foreground Service · Jetpack Glance. `minSdk 26`, `targetSdk 36`, один модуль `app`.

Структура пакетов (`app/src/main/java/com/iron/fitness`):

| Пакет | Что внутри |
|---|---|
| `core/ui` | темы (цветовые токены), типографика, общие компоненты, иконки |
| `core/db` | база Room, конвертеры |
| `core/settings` | настройки в DataStore |
| `core/util` | форматирование чисел, дат, русская локаль |
| `core/ai` | сетевой слой Gemini, хранилище ключа |
| `core/backup` | бэкап ZIP, восстановление, Google Диск |
| `navigation` | маршруты, нижняя панель, граф навигации |
| `feature/*` | разделы приложения (каждый со своими data/ui) |

## Сборка локально

Нужны JDK 17 и Android SDK (платформа 36).

```bash
./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest    # юнит-тесты
```

## Сборка APK в GitHub Actions

Файл `.github/workflows/build.yml` запускается при каждом пуше:

* если в репозитории заданы секреты подписи — собирается **подписанный release-APK**;
* если секретов нет — собирается **debug-APK**, подписанный постоянным debug-ключом из
  `app/debug.keystore` (ключ лежит в репозитории, поэтому подпись между сборками не меняется);
* APK выкладывается как артефакт сборки (вкладка **Actions** → нужный запуск → **Artifacts**);
* при пуше в `main` дополнительно создаётся релиз GitHub (`v1.0.<номер сборки>`) с APK во вложении.

Номер версии (`versionCode`) равен номеру запуска workflow, поэтому каждая новая сборка ставится
поверх предыдущей без потери данных.

### 1. Создать свой ключ подписи (один раз)

```bash
keytool -genkeypair -v \
  -keystore iron-release.jks \
  -alias iron \
  -keyalg RSA -keysize 4096 -validity 36500 \
  -storetype PKCS12
```

keytool спросит пароль хранилища и данные владельца (можно заполнить любыми). Для PKCS12 пароль ключа
совпадает с паролем хранилища. **Сохраните файл `iron-release.jks` и пароль в надёжном месте** — без них
нельзя будет выпустить обновление, которое встанет поверх установленного приложения.

Закодировать ключ в base64:

```bash
base64 -w0 iron-release.jks > iron-release.jks.b64     # Linux
base64 -i iron-release.jks -o iron-release.jks.b64     # macOS
```

### 2. Добавить секреты в репозиторий

GitHub → репозиторий → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**:

| Имя | Значение |
|---|---|
| `KEYSTORE_BASE64` | содержимое файла `iron-release.jks.b64` |
| `KEYSTORE_PASSWORD` | пароль хранилища |
| `KEY_ALIAS` | `iron` (алиас из команды выше) |
| `KEY_PASSWORD` | пароль ключа (для PKCS12 — тот же, что у хранилища) |

> ⚠️ Подпись должна быть всегда одной и той же. Если вы сначала поставили debug-APK, а затем
> перешли на release-ключ, Android откажется ставить обновление поверх: сделайте бэкап
> (Ещё → Бэкап), удалите приложение, поставьте новую сборку и восстановите бэкап.
> Лучше добавить секреты **до первой установки**.

### 3. Скачать APK

* **Релизы**: страница репозитория → **Releases** → последний `IRON 1.0.N` → файл `IRON-1.0.N.apk`.
* **Артефакты** (любая ветка): **Actions** → последний успешный запуск «Сборка APK» → блок
  **Artifacts** → архив `IRON-1.0.N` (внутри APK).

### 4. Установить на телефон

1. Скачайте APK на телефон (из браузера или перекиньте файлом).
2. Откройте файл. Android спросит разрешение на установку из этого источника:
   **Настройки → Приложения → Специальный доступ → Установка неизвестных приложений** →
   выберите браузер/файловый менеджер → **Разрешить из этого источника**.
3. Вернитесь назад и нажмите **Установить**. Если появится предупреждение Play Защиты —
   **Подробнее → Всё равно установить**.
4. Обновления ставятся так же, поверх: данные сохраняются, пока подпись не меняется.

## Бэкап и Google Диск

**Ещё → Бэкап.** В бэкап входят база (все записи), настройки и фото. Не входят ключ Gemini
(он только на телефоне, в зашифрованном хранилище) и кэш картинок упражнений.

* **Сохранить в файл / Восстановить из файла** — ZIP-архив через системный диалог: «Загрузки»,
  флешка, любое облако. Работает без настройки.
* **Google Диск** — копии лежат в скрытой папке приложения (`appDataFolder`): их видит только IRON,
  место считается в квоте Диска. Кнопки «Сделать сейчас», «Восстановить» у каждой копии,
  переключатель «Ежедневно по Wi-Fi» (WorkManager, раз в сутки при Wi-Fi и нормальном заряде).
  Хранятся последние 7 копий.
* Восстановление заменяет все текущие данные и перезапускает приложение.

### Разовая настройка Google Cloud для Диска

Google пускает приложение к Диску, только если в вашем проекте Google Cloud есть OAuth-клиент
типа Android с **именем пакета и SHA-1 ключа подписи** этой сборки. Ключи и ID в код вписывать не нужно.

1. Откройте [console.cloud.google.com](https://console.cloud.google.com/) и создайте проект (например, `IRON`).
2. **APIs & Services → Library** → найдите **Google Drive API** → **Enable**.
3. **Google Auth Platform** (раньше назывался «OAuth consent screen») → **Get started**:
   * App name — `IRON`, User support email — ваш адрес;
   * Audience — **External**;
   * Contact information — ваш адрес → **Create**.
4. **Google Auth Platform → Data Access → Add or remove scopes** → отметьте
   `.../auth/drive.appdata` → **Update** → **Save**.
5. **Google Auth Platform → Audience**:
   * либо **Test users → Add users** → ваш Gmail (в режиме Testing вход придётся повторять
     раз в 7 дней — автобэкап пришлёт уведомление);
   * либо **Publish app → In production** — тогда вход не истекает. Приложение использует только
     нечувствительную область `drive.appdata`, проверка Google для неё не требуется.
6. **Google Auth Platform → Clients → Create client** → Application type **Android**:
   * Package name — `com.iron.fitness`;
   * SHA-1 certificate fingerprint — отпечаток ключа, которым подписан ваш APK:
     * **release-сборка** (заданы секреты подписи):
       ```bash
       keytool -list -v -keystore iron-release.jks -alias iron | grep SHA1
       ```
     * **debug-сборка** (секретов нет, ключ `app/debug.keystore` из репозитория):
       `86:98:74:BC:18:EB:62:94:5B:D8:B0:3E:70:93:31:34:8C:43:6A:49`
   * Если ставите и ту, и другую сборку — создайте два Android-клиента.
7. Подождите 5–10 минут и в приложении нажмите **Ещё → Бэкап → Подключить Google Диск**.

Если приложение пишет «не зарегистрировано в Google Cloud» — не совпадает имя пакета или SHA-1
(или клиент ещё не применился). «Не включён Google Drive API» — пропущен шаг 2.
